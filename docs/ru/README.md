# game-proto

Канонический источник: [English](../en/README.md).

`@playbro-tech/game-proto` определяет protobuf-сообщения, enum и дескриптор сервиса
для игровых интеграций. Пакет собирает ESM-библиотеку с декларациями TypeScript и
генерирует OpenAPI по аннотированным RPC-методам. В манифесте указана версия
`0.5.6`; справочник описывает исходники текущего checkout, которые могут содержать
изменения сверх опубликованного артефакта. Перед использованием поля в выпущенной
зависимости проверяйте установленные дескрипторы.

## Границы ответственности

Пакет предоставляет схемы и сгенерированные экспорты. Приложение отвечает за сеть,
аутентификацию, корреляцию запросов, повторы, оболочки ошибок, бизнес-валидацию и
жизненный цикл игры. HTTP/WebSocket-клиент, игровая математика, UI, FSM,
мок-сервер и автоматический запуск раундов здесь не реализованы.

Есть две группы API. `api.base.v1` моделирует команды сессии с состоянием из
`common.v1` и `domain.v1`. `api.game.v1` используется аннотированным
`services.v1.GameService` и возвращает последовательности `base.v1.Step`.
Одна группа не заменяет и не преобразует другую автоматически.

## Структура репозитория и команды

`proto/` владеет протоколом. `plugins/` содержит генераторы точки входа и OpenAPI.
`tests/` содержит проверки wire-контракта. `docs/en/` и `docs/ru/` содержат
согласованную документацию. Сгенерированные `src/`, `dynamic/` и `dist/`
игнорируются Git; `docs/openapi.yaml` — отдельный отслеживаемый документ,
который Redocly не использует в качестве выбранного входа.

Для разработки используются pnpm `10.12.1` и установленные dev-зависимости.
`pnpm proto:generate` генерирует сообщения и OpenAPI; `pnpm test` проверяет
wire-контракт gift mode и Buf lint; `pnpm build` собирает пакет;
`pnpm docs:build` отображает сгенерированный OpenAPI через Redocly. Порядок
действий и prerequisites описаны в [разработке](development.md).
